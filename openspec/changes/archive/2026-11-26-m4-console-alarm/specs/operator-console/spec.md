# Spec Delta

## ADDED Requirements

### Requirement: 事件与故障告警
调度台 SHALL 展示带来源的任务、车队和故障事件，避免同一故障状态的周期消息填满列表。

#### Scenario: 周期故障消息
- **WHEN** 故障监控连续发布相同状态并随后恢复
- **THEN** 界面记录故障和恢复转换，并保留消息和来源

### Requirement: 连接中断与恢复
调度台 SHALL 显示快照是否可用及连接状态，恢复时更新路网和快照。已有写请求按各自回执或超时显示。

#### Scenario: 快照服务重启
- **WHEN** 快照读取中断后恢复
- **THEN** 界面标明断开并在新的快照和路网应答后恢复连接显示，期间保持最后可用地图

### Requirement: 仿真车队停止控制
启用该能力的轻量仿真车队 SHALL 在停止设定有效或控制状态过期时保持静止。调度台 SHALL 提供停止及需确认的解除入口，并区分后端回执、状态主题和实际运动。

#### Scenario: 运动中停止并解除
- **WHEN** 操作员停止正在执行任务的车队
- **THEN** 启用门控的代理停止运动，现有任务与路权保留；操作员确认解除后代理按原状态继续

#### Scenario: 控制状态中断
- **WHEN** 控制状态超过有效时间
- **THEN** 代理停止运动，调度台提示状态未知

### Requirement: Ubuntu 安装入口
Ubuntu 安装 SHALL 提供可直接从工作区启动实时调度台和回放的入口。

#### Scenario: 使用安装树
- **WHEN** 使用 Ubuntu 上的安装产物启动调度台和回放
- **THEN** 两种启动方式均能打开对应窗口
