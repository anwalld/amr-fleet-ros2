# Spec Delta

## ADDED Requirements

### Requirement: 调度台操作夜跑验收
阶段 7 SHALL 保留无人操作的六车冒烟，并在隔离场景中经实际调度台入口执行验收基线列出的操作。每个登记用例 SHALL 恰有一条结果及对应的请求、回执或超时、独立状态观测证据。阶段 8 SHALL 展示冒烟与操作专项的独立判定及原始证据位置。

#### Scenario: 必跑用例缺失或证据不足
- **WHEN** 冒烟通过，但某个登记用例缺失、重复、失败、跳过或缺少证明其断言的证据
- **THEN** 阶段 7 判为失败，报告指出具体用例与原因

#### Scenario: 首轮及后续比较
- **WHEN** 首轮冒烟与全部登记的操作场景均通过，且证据完整
- **THEN** 保存版本、场景条件、逐项结果和证据引用；后续运行按相同用例键和已记录的基线比较，区分功能结果和指标差异
