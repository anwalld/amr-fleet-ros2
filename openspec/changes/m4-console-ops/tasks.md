# Tasks

## 1. 路权服务

- [x] 1.1 在 `robot_interfaces_mission` 定义预览和带条件的清理服务。用 Ubuntu colcon 构建，核对请求与响应字段，并核对旧清理服务定义的差异为空。核实清理结果为明确的成功、冲突或错误，调用方无需解析提示文本。
- [x] 1.2 在 TrafficService 接入共用的清理影响计算和条件判断，保持校验与修改在同一次串行回调。用 GoogleTest 验证封路标记、多项车辆占用、暂停组、资源消失、换占用者、原占用者的资源或暂停组变化及集合顺序差异。
- [x] 1.3 复用现有清理与补授予路径。回归测试覆盖匹配时释放全部预期占用和解除暂停、冲突时无清理或补授予副作用，以及旧入口保留既有行为。覆盖同车多工单共享资源和旧任务号，核对预览列出的释放范围与实际释放一致。

## 2. 调度台操作通路

- [x] 2.1 在 Qt 核心加入可选操作接口，在 RosBridge 中接入目标服务、线程安全的操作投递和退出清理；在 robot_console 的构建目标和包清单中声明 robot_interfaces_fleet。使用 QtTest 替身和 ROS 转换测试核对目标与字段，验证回放不产生请求、无操作时沿用 Core 的三个读取服务。
